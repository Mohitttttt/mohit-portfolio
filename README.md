## Featured Project

### Enterprise AI Knowledge Intelligence Platform

An AI-powered document intelligence application designed to help users search and interact with information from uploaded documents.

Key capabilities:

- PDF, DOCX, and TXT document ingestion
- Semantic search using vector embeddings
- BM25 keyword retrieval
- Hybrid search with Reciprocal Rank Fusion
- Conversational question answering using RAG
- Retrieval evaluation and benchmarking
- Docker-based environment and automated testing

[View Project on GitHub](https://github.com/Mohitttttt/enterprise-ai-knowledge-platform)

## Run Locally

Clone the repository and install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

Create a production build:

```bash
npm run build
```
